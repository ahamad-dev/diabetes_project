# 🩺 Diabetes Prediction System

A complete Machine Learning project for Diabetes prediction using the Pima Indians Diabetes Database.

## 📁 Project Structure

```
diabetes_project/
│
├── diabetes_analysis.ipynb     ← Jupyter Notebook (EDA + Training)
├── app.py                      ← Flask Web Application
├── requirements.txt            ← Python dependencies
├── README.md                   ← This file
│
├── templates/
│   └── index.html              ← HTML UI
│
├── static/                     ← Saved plots (auto-generated by notebook)
│   ├── outcome_distribution.png
│   ├── correlation_heatmap.png
│   ├── feature_distributions.png
│   ├── confusion_matrices.png
│   ├── roc_curves.png
│   ├── model_comparison.png
│   └── feature_importance.png
│
└── models/                     ← Saved ML models (auto-generated by notebook)
    ├── logistic_regression.pkl
    ├── decision_tree.pkl
    └── scaler.pkl
```

## 🚀 Quick Start

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Download Dataset
- Go to: https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
- Download `diabetes.csv`
- Place it in the **project root folder** (same level as the notebook)

### Step 3: Run Jupyter Notebook
```bash
jupyter notebook diabetes_analysis.ipynb
```
Run all cells to:
- Perform EDA and generate visualizations
- Train Logistic Regression & Decision Tree models
- Save models to `models/` folder

### Step 4: Start Flask App
```bash
python app.py
```

### Step 5: Open in Browser
```
http://localhost:5000
```

## 🤖 Algorithms

| Algorithm | Description |
|-----------|-------------|
| **Logistic Regression** | Uses sigmoid function for binary classification. Fast, interpretable. |
| **Decision Tree** | Splits data on thresholds. Captures non-linear patterns. |

## 📊 Dataset Features

| Feature | Description |
|---------|-------------|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration (mg/dL) |
| BloodPressure | Diastolic blood pressure (mmHg) |
| SkinThickness | Triceps skinfold thickness (mm) |
| Insulin | 2-Hour serum insulin (mu U/ml) |
| BMI | Body mass index (kg/m²) |
| DiabetesPedigreeFunction | Diabetes pedigree function (family history) |
| Age | Age in years |
| **Outcome** | **0 = No Diabetes, 1 = Diabetes (Target)** |
